## Changes

Tailwind4 theme/utilities use the `tw` prefix, AH semantic tokens and no Preflight. Owned shadcn-pattern Button/Input/Card/Badge use native semantics; Dialog/Tabs use Radix. Lucide icons are decorative where the control already has an accessible name. Existing page CSS remains during migration. Native selects and Heatmap marker geometry/styles remain unchanged.

Trial expanded map and Participant give-up dialogs now trap keyboard focus, close with Escape and return focus. The participant cannot dismiss the dialog while a terminal request is pending. Results tabs support arrow navigation. Contrast defects found by axe were repaired with existing AH semantic colors. Native form bodies, URLs, API, schema, Auth/RLS, tracking, calculation, version and evidence contracts remain unchanged.

## Preview and completion rules

Run against a ready deployment whose metadata names the exact remote commit. `UTP_UI_QA_BASE_URL` accepts localhost or an explicit hashed UTP Preview hostname and rejects Production. The protected Preview helper reads its access URL through private stdin and keeps origin-scoped cookies in memory; it does not save credentials, pass access URLs as command arguments or enable Preview traces. Never publish access URLs or authentication state in evidence.

The Foundation Preview passed six public/form accessibility tests. Its expanded-map test failed on the old native dialog before the Trial migration; the new Radix dialog must be checked on the Trial/final Preview before marking that scope COMPLETE. Record final Preview results and CI links in the PR and live Sheet; do not infer runtime success from a READY build.

Real researcher account/published-study smoke remains `BLOCKED_EXTERNAL`. Keep UI-01 overall in QA until that evidence is available.
